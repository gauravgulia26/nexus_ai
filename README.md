## 📌 What is Nexus Ai?

**Nexus Ai** is a high-end, terminal-inspired engineering command center and portfolio interface designed specifically for specialized **AI/ML Engineers, MLOps Practitioners, and Generative AI Architects**. 

Departing from conventional developer portfolios, Nexus Ai fuses the tactile aesthetics of a modern Unix terminal with glassmorphism, luminous neural mesh backgrounds, spring-damped motion physics, and an interactive command-line environment.

---

## 🌟 5 High-Impact Pillars of Nexus Ai

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           NEXUS AI CAPABILITIES                         │
└─────────────────────────────────────────────────────────────────────────┘
  1. Interactive Command Console (CLI Mode) ──────────> Real-Time Shell
  2. "Skynet is Loading" Boot Engine ─────────────────> CUDA Diagnostics
  3. Luminous Glassmorphic Design System ─────────────> 24px Blur & Mesh
  4. Ambient Brush Tracker & Terminal Cursor ─────────> Dynamic Physics
  5. Zero-Layout-Shift Production Architecture ───────> Next.js 16 + Tw4
```

### 1. 🖥️ Interactive Command-Line Console (`CLI_MODE`)
* **Real-time Shell Emulator**: Built-in bash parser accessible via the **`~`** (tilde) shortcut or the navbar **`CLI_MODE`** button.
* **Intelligent Command Router**: Evaluates commands such as `help`, `whoami`, `about`, `skills`, `projects`, `research`, `exp`, `metrics`, `contact`, `download`, and `clear` with real-time autocompletion chips.

### 2. ⚡ "Skynet is Loading..." Autonomous Boot Sequencer
* **Authentic Diagnostic Loader**: Simulates a multi-subsystem machine learning kernel boot sequence with progress tracking and CUDA acceleration telemetry.
* **Animated Viewport Dissolve**: Smooth transition sequence lasting at least **1.5+ seconds** with keyboard bypass (`ESC to skip`) and session memory persistence.

### 3. 🌌 Luminous Cyber-Mesh & Glassmorphism System
* **Deep Graphite Palette**: Near-black obsidian backdrop (`#05070b`) layered with ambient breathing gradient spheres (cyan `#00f0ff`, emerald `#10b981`, indigo `#818cf8`).
* **Ultra-Crisp Frosted Glass**: Multi-density glass panels engineered with `backdrop-filter: blur(24px)`, specular border highlights, and inset depth shadows.

### 4. 🎯 Precision Cursor Physics & Custom Terminal Scrollbar
* **Ambient Mouse Brush Light**: A smooth spring-damped radial glow (`450px`) that tracks cursor coordinates with fluid inertia.
* **Blinking Terminal Block Cursor**: Custom high-tech green/cyan blinking block cursor (`█`) with active `[CMD]` state triggers over clickable surfaces.
* **Custom Terminal Scrollbar**: Glowing electric cyan scroll thumb and track replacing browser-native scrollbars across WebKit and Gecko engines.

### 5. 🚀 Modern Edge-Ready Static Architecture
* **Turbopack Compilation**: Powered by **Next.js 16**, **React 19**, **Tailwind CSS v4**, and **TypeScript 5**.
* **Zero Layout Shift (CLS 0)**: Complete static prerendering with sub-second initial load times and fluid responsive adaptations from mobile (320px) to 4K displays.

## ⚡ Quickstart & Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/nexus_ai.git
cd nexus_ai
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 4. Build Production Bundle
```bash
npm run build
npm run start
```
